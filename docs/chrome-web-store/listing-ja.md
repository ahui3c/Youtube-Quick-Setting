# Chrome Web Store 掲載情報（日本語）

## 名前

YouTube クイック設定ツールボックス

## 概要

YouTube 通常動画の再生速度・画質・チャンネル別設定を自動適用し、ショートには個別の速度設定とキーボード操作を提供します。

## 詳細説明

YouTube 動画を開くだけで、いつもの再生速度と画質を自動的に適用します。

主な機能：

- 通常動画とショートで別々の初期設定
- 再生速度：0.7×、1×、1.25×、2×、3×
- 画質：利用可能な最高画質、4K、1080p
- 指定画質がない場合、目標を超えない範囲で最も高い画質を自動選択
- Premium 高画質は独立した任意設定で、既定では 1080p Premium を選択しません
- チャンネル別設定を全体設定より優先
- 通常動画の次の動画の自動再生を無効化可能。既定はオフで設定を保存
- 終了画面のおすすめを非表示にし、プレーヤーにポインターを重ねた時だけ表示可能。既定はオフで設定を保存
- チャンネル設定の適用時、動画右下に 2 秒間の通知を表示
- PgUp キーで減速、PgDn キーで加速、Home キーですぐに 1×へ復帰
- S キーでタイトル＋URL をコピーし、確認表示中に F／X／T を押すと Facebook／X／Threads を開きます。Shift+S はタイトル＋現在位置 URL をコピーします
- ポップアップのボタンまたは Ctrl+S で、プレーヤーやページ UI を含まない動画フレームを PNG 保存またはクリップボードへコピー
- 360° 動画では S／Shift+S を取得せず、YouTube 標準の全景視点操作に使用できます
- 矢印メニューには5種類のコピー形式と、タイトル＋リンクを Facebook、X、Threads へ直接共有する項目があります
- JSON 設定の書き出し／読み込み、結合／置換プレビュー、端末内の自動復元ポイントに対応
- ショートでは ←／→ キーを 3、5（既定）、10 秒から選択、または無効化でき、0 キーでいつでも先頭へ復帰
- ホームのショートカードにクリック可能なチャンネル名を追加。公開時刻は既定でオフで、オンにするとホームのカードとショート再生ページに表示
- 相対時刻を、形式を指定できる絶対アップロード日時に任意で置換
- 速度変更を画面表示し、YouTube の設定メニューにも反映
- 繁體中文、English、日本語に対応。システム言語連動または手動選択
