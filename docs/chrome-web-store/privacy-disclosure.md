# Chrome Web Store 隱私權揭露填表草稿

## 單一用途

在 YouTube 一般影片與 Shorts 頁面，依使用者偏好自動套用播放速度及可用畫質，提供鍵盤快速操作、影片標題與網址複製、使用者主動觸發的 Facebook 分享、畫面提示，以及首頁 Shorts 頻道名稱和首頁／播放頁發布時間。

## 權限理由

### storage

儲存使用者選擇的播放速度、畫質、一般影片與 Shorts 設定、頻道專屬設定及介面語言。資料使用 Chrome storage.sync；開發者不接收或存取資料。

### activeTab

僅在使用者點擊擴充功能按鈕時辨識目前作用中的分頁是否為 YouTube 影片，並取得該影片的本機頁面情境以顯示及編輯正確設定。

### clipboardWrite

僅在使用者點擊複製按鈕、選擇複製格式或於 YouTube 影片頁按下 S／Shift+S 時，把目前影片標題、公開網址、目前時間點或頻道名稱依所選格式寫入系統剪貼簿。本擴充功能不讀取剪貼簿內容，也不會自動複製。

### 主機權限 https://www.youtube.com/*

在 YouTube 影片與 Shorts 頁面讀取影片類型及頻道識別資訊，控制 HTML5 播放速度、呼叫 YouTube 播放器可用畫質介面、同步設定面板顯示值、呈現套用結果提示，並從 YouTube 當頁資料或公開影片頁面取得首頁可見 Shorts 的頻道名稱及首頁／播放頁發布日期。權限不會用於其他網站。

### web_accessible_resources

只公開套件內的 page-bridge.js 給 youtube.com，用於與 YouTube 頁面播放器介面通訊。沒有從網路下載或執行任何程式碼。

## 遠端程式碼

否。本擴充功能的所有 JavaScript 都包含在提交的套件內；不下載、載入或執行遠端程式碼，也不使用 eval 或外部 CDN。

## 資料使用揭露

- 個人識別資訊：否
- 健康資訊：否
- 財務及付款資訊：否
- 驗證資訊：否
- 個人通訊：否
- 位置資訊：否
- 網頁瀏覽記錄：不收集或傳送；只在目前開啟的 youtube.com 分頁本機判斷影片 URL 類型
- 網站內容：是。在本機暫時讀取目前影片的標題、公開網址、發布日期與頻道名稱／識別資訊；標題及網址只在使用者主動操作後寫入系統剪貼簿。只有使用者於複製提示期間再次按下 S，或主動選擇 Facebook 分享選單時，才會將目前影片的公開標題與網址加入 Facebook 分享網址並傳送至 Facebook。首頁 Shorts 公開網址只傳送回 YouTube；所有資料均不傳送給開發者
- 本機設定檔：使用者主動匯出或匯入 JSON；差異預覽及匯入前還原點只在使用者裝置內處理，不會上傳
- 使用者活動：否

## Limited Use 認證

資料使用僅限於提供商店頁面所述的單一用途；不出售、不用於廣告或信用評估，也不允許人工閱讀使用者資料。只有使用者明確要求 Facebook 分享時，才會將該支公開影片的標題與網址傳送至 Facebook，以完成使用者要求的分享動作。
