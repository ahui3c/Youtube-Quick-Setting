# Chrome Web Store 商店資訊（繁體中文，預設）

## 名稱

YouTube 快速設定工具箱

## 摘要

自動套用 YouTube 一般影片的播放速度、畫質與頻道設定，並提供 Shorts 獨立速度與方向鍵快速操作。

## 詳細說明

每次打開 YouTube 影片，就自動用你習慣的速度與畫質播放。

主要功能：

- 一般影片與 Shorts 使用獨立預設
- 首頁與訂閱內容頁可分別設定一般影片／Shorts 每行 2～6 部，或維持跟隨 YouTube
- 播放速度：0.7×、1×、1.25×、2×、3×
- 畫質：自動最高、4K、1080p
- 指定畫質不存在時，自動選擇不超過目標的相對最高可用畫質
- Premium 強化畫質為獨立選用開關，預設不會選擇 1080p Premium
- 可為目前頻道建立專屬設定，優先於全域預設
- 可自動關閉一般影片的「自動播放下一部影片」開關，預設關閉並記錄設定
- 可隱藏影片結尾的推薦卡，滑鼠移入播放器時暫時恢復顯示；預設關閉並記錄設定
- 套用頻道設定時，在影片右下角顯示兩秒提示
- PgUp 鍵減速、PgDn 鍵加速，Home 鍵快速恢復 1×
- 按 S 複製標題＋網址，提示期間按 F／X／T 開啟 Facebook／X／Threads；Shift+S 複製標題＋目前時間點網址
- 按面板按鈕或 Ctrl+S，一鍵下載或複製不含播放器與網頁 UI 的純影片 PNG 畫面
- 播放 360° 全景影片時不攔截 S／Shift+S，保留 YouTube 原生全景視角操作
- 右側箭頭提供五種複製格式，並可直接將標題＋連結分享到 Facebook、X 或 Threads
- 設定可匯出／匯入 JSON，匯入前可預覽合併或完全取代的變更，並自動建立本機還原點
- Shorts 支援 ←／→ 前後跳轉 3、5（預設）或 10 秒，可關閉方向鍵；按 0 隨時回到片頭
- 首頁 Shorts 卡片可補上可點擊的頻道名稱；發布時間功能預設關閉，開啟後會顯示於首頁卡片與 Shorts 播放頁
- 絕對上傳日期功能預設關閉；可將「2 週前」改為自訂格式的日期與時間
- 調速時顯示畫面提示，YouTube 設定面板也會同步反映速度
- 繁體中文、English、日本語介面，可跟隨系統或手動選擇
