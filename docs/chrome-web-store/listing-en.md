# Chrome Web Store listing (English)

## Name

YouTube Quick Settings Toolbox

## Summary

Automatically apply speed, quality, and per-channel settings to standard YouTube videos, with separate Shorts speed and keyboard controls.

## Description

Open any YouTube video and start watching at your preferred speed and quality automatically.

Key features:

- Separate defaults for regular videos and Shorts
- Independently set 2–6 regular videos or Shorts per row on Home and Subscriptions, or keep YouTube's responsive default
- Playback speeds: 0.7×, 1×, 1.25×, 2×, and 3×
- Quality targets: Highest available, 4K, and 1080p
- Falls back to the highest available quality that does not exceed your target
- Premium enhanced quality is a separate opt-in and is never selected by default
- Per-channel profiles override global defaults
- Can disable YouTube's autoplay-next toggle for standard videos; off by default and remembered
- Can hide end-screen recommendations until the pointer hovers over the player; off by default and remembered
- A two-second on-video notice confirms applied channel settings
- Use PgUp to slow down, PgDn to speed up, and Home to return instantly to 1×
- Press S to copy the title + URL, then press F/X/T during the confirmation to open Facebook/X/Threads; Shift+S copies the title + current timestamp URL
- Use the popup button or Ctrl+S to download or copy a clean PNG video frame without player or page UI
- On 360° videos, S and Shift+S remain available to YouTube's native spherical-view controls
- The arrow menu offers five copy formats plus direct title + link sharing to Facebook, X, and Threads
- Export or import JSON settings with merge/replace preview and an automatic local restore point
- In Shorts, use ← / → to seek 3, 5 (default), or 10 seconds, optionally disable the arrow keys, and press 0 to return to the beginning
- Adds clickable channel names to Home Shorts cards; optional publish times are off by default and can be shown on Home cards and Shorts playback pages
- Optional absolute upload dates replace relative times with a customizable date and time format
- On-screen speed feedback and synchronized YouTube settings-menu values
- Traditional Chinese, English, and Japanese UI; follow the system language or choose manually

The extension contains no ads, trackers, analytics, remote code, or developer-operated data collection.
