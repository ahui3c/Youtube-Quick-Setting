# v1.5.0

## 新功能

- YouTube 首頁 Shorts 卡片可顯示可點擊的頻道名稱，預設開啟。
- 新增「顯示預估踩數」，預設關閉；使用者授權後，從 Return YouTube Dislike 讀取第三方推算數字。
- 預估踩數以 `≈` 標示，並提供清楚的資料來源連結，不會回傳使用者的按讚或倒讚操作。

## 穩定性與隱私

- Shorts 頻道名稱加入請求鎖與重複清理，避免同一卡片顯示兩列。
- 預估踩數使用 6 小時記憶體快取、8 秒逾時與 API 限流退避。
- 僅在使用者啟用功能時申請第三方 API 網域權限；關閉後移除權限。
- 若 YouTube 已提供數字或偵測到其他踩數插件，便不重複插入。
