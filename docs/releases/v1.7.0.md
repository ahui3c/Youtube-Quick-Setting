# v1.7.0

## Shorts 發布時間資訊

- 在 YouTube 首頁的 Shorts 卡片觀看次數後顯示相對發布時間，例如「2 天前」。
- 在 Shorts 播放頁的頻道資訊與影片標題之間顯示相對發布時間。
- Shorts 設定新增「Shorts 顯示發布時間資訊」獨立開關，第一次安裝時預設關閉；開啟後同時控制首頁卡片與播放頁，不影響頻道名稱開關。
- 只處理目前畫面附近的卡片，查詢結果只在目前頁面快取。
- 播放頁優先讀取 YouTube 已載入的發布日期資料，避免不必要的額外請求。
- 視窗縮小、發布時間移入影片畫面時，自動切換為白字與深色半透明底，移回外側資訊區則恢復一般文字色。
- 加入重複標記清理，避免 YouTube 動態重繪或切換 Shorts 後出現雙層發布時間。
- 繁體中文、English、日本語介面與相對時間格式同步支援。

## 隱私與權限

- 發布日期只從 YouTube 自己的公開影片頁面取得，請求不攜帶登入 Cookie。
- 沒有新增 Chrome 權限、第三方服務、追蹤器或遠端程式碼。
