# v1.7.0

## 首頁 Shorts 發布時間

- 在 YouTube 首頁的 Shorts 卡片觀看次數後顯示相對發布時間，例如「2 天前」。
- Shorts 設定新增「首頁 Shorts 顯示發布時間」獨立開關，預設啟用，不影響頻道名稱開關。
- 只處理目前畫面附近的卡片，查詢結果只在目前頁面快取。
- 加入重複標記清理，避免 YouTube 動態重繪後出現雙層發布時間。
- 繁體中文、English、日本語介面與相對時間格式同步支援。

## 隱私與權限

- 發布日期只從 YouTube 自己的公開影片頁面取得，請求不攜帶登入 Cookie。
- 沒有新增 Chrome 權限、第三方服務、追蹤器或遠端程式碼。
