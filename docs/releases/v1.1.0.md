# YouTube Quick Setting v1.1.0

## 繁體中文

第一個公開版本，提供：

- 一般影片與 Shorts 的獨立播放速度、畫質偏好
- 全域預設與頻道專屬覆寫
- 1080p Premium 優先與相對最高畫質後備選擇
- `+`／`-` 調速與 `*` 恢復 `1×`
- 頻道設定生效時的兩秒播放器提示
- 繁體中文、英文、日文介面

下載 ZIP、解壓縮後，在 `chrome://extensions/` 開啟開發人員模式並選擇「載入未封裝項目」。

## English

The first public release includes:

- Independent speed and quality profiles for standard videos and Shorts
- Global defaults with per-channel overrides
- 1080p Premium preference and nearest-quality fallback
- `+` / `-` speed control and `*` reset to `1×`
- A two-second player notice when channel settings apply
- Traditional Chinese, English, and Japanese interfaces

Download and extract the ZIP, enable Developer mode on `chrome://extensions/`, and select **Load unpacked**.

## 日本語

最初の公開バージョンには、次の機能が含まれます。

- 通常動画とショートの再生速度・画質を個別設定
- 全体設定とチャンネル別の優先設定
- 1080p Premium の優先と最適な代替画質の選択
- `+`／`-` による速度変更と `*` による `1×` への復帰
- チャンネル設定適用時の2秒間のプレーヤー通知
- 繁体字中国語、英語、日本語のインターフェース

ZIP をダウンロードして展開し、`chrome://extensions/` でデベロッパーモードを有効にして、**パッケージ化されていない拡張機能を読み込む**を選択してください。

## Package

- `YouTube-Quick-Setting-v1.1.0.zip`
- Chrome Manifest V3
- SHA-256 checksum is included as a separate release asset
