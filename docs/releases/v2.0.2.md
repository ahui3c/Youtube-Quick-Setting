# YouTube 快速設定工具箱 v2.0.2

## 多版本衝突防護

- 新增 Chrome 商店版與未封裝開發版的互相偵測機制。
- 同時安裝時由較新版本啟用功能，較舊版本自動暫停，避免重複調整播放器與重複顯示提示。
- 版本號相同時優先啟用未封裝開發版，Chrome 商店版會暫停並顯示 `OLD` 狀態。

## YouTube 畫質選單修正

- 修正影片載入時，YouTube 右下角畫質選單偶爾自行彈出的問題。
- 畫質調整會等待選單內容真正完成載入，完成後也會主動確認選單已關閉。
- 選單操作過程加入隱藏交易狀態，降低自動設定時對觀看畫面的干擾。

## 子母畫面相容性

- 改善與 Picture-in-Picture Floating Video Player 等子母畫面擴充元件的相容性。
- 支援偵測瀏覽器原生 PiP、Document Picture-in-Picture，以及由第三方擴充元件移動影片節點的模式。
- 進入 PiP 後暫停畫質、播放器介面與播放位置的延遲重試，離開 PiP 後再安全恢復，避免播放器互相搶奪控制權。

## 跨瀏覽器建置

- 補齊 Chrome、Firefox 與 Safari-ready 的隔離建置流程，不會覆寫 Chrome 主版本原始碼。
- GitHub Release 同時提供 Chrome 安裝包與 Firefox 未簽署安裝包及 SHA-256 校驗檔。
- Safari 版本目前維持開發準備狀態，尚未作為可直接安裝的正式版本發佈。
