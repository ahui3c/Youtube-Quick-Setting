# v1.6.0

## 強化複製

- 主按鈕使用目前預設格式，右側箭頭提供五種複製格式。
- 支援標題＋網址、標題＋目前時間點網址、Markdown、HTML、頻道＋標題＋網址。
- `S` 使用目前預設格式；`Shift+S` 固定複製標題＋目前播放時間點網址。
- 面板與影片畫面都會顯示複製結果及內容摘要。

## 設定備份與還原

- 支援格式版本 `v2` JSON 匯出與匯入。
- 匯入前預覽一般設定及頻道新增、更新、移除數量。
- 可選擇合併設定或完全取代。
- 套用前自動在本機建立匯入前還原點。
- 舊設定會自動遷移並加入格式版本與預設複製格式。

## 隱私與權限

- 設定檔、匯入預覽及還原點皆在使用者裝置內處理。
- 沒有新增 Chrome 權限、外部服務、追蹤器或遠端程式碼。
