# YouTube 快速設定工具箱 v1.8.0

## 名稱更新

- 插件名稱更新為「YouTube 快速設定工具箱」。
- 英文名稱同步更新為「YouTube Quick Settings Toolbox」。
- 日文名稱同步更新為「YouTube クイック設定ツールボックス」。
- 同步更新三語 README、Chrome 商店文案、隱私權政策、操作畫面與宣傳素材。

## 複製影片資訊

- 插件主按鈕與 `S` 快速鍵固定複製「標題＋網址」。
- `Shift + S` 維持複製「標題＋目前播放時間點網址」。
- 右側箭頭選擇其他格式時只執行單次複製，不再改變主按鈕與快速鍵的預設格式。
- 舊設定即使曾選擇 Markdown 等格式，也會遷移回新的固定預設。

## Facebook 分享

- 第一次按 `S` 複製成功後，提示顯示期間再按一次 `S`，會開啟 Facebook 分享視窗並帶入影片標題與網址。
- 複製格式下拉選單最後新增「分享標題＋連結到 Facebook」，可直接開啟相同的分享視窗。
- 加入 Facebook 分享成功提示與彈出視窗阻擋錯誤提示。
- 分享是使用者主動觸發的動作，不新增 Facebook 主機權限；隱私權政策與 Chrome 商店資料揭露已同步更新。

## 品質與相容性

- 維持一般影片、Shorts、頻道專屬速度／畫質與劇院模式設定。
- 維持 Shorts 首頁頻道名稱與可選的發布時間資訊功能。
- 繁體中文、English、日本語介面完整支援。
- 全部自動化測試通過。
