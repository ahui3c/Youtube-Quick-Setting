# YouTube 快速設定工具箱 v1.9.1

## Shorts 設定簡化

- 移除無法穩定生效的 Shorts 畫質選項，避免介面顯示實際無作用的設定。
- Shorts 播放時不再向 YouTube 播放器送出畫質切換要求；一般影片畫質設定維持不變。
- 將「快進秒數」移到「啟用 Shorts 左右方向鍵」下方。
- 方向鍵功能關閉時，3／5／10 秒選項會同步停用，開啟後才可設定。
- 快速操作說明會依方向鍵開關即時更新。

## Shorts 顯示與操作改善

- Shorts 的速度、快退／快進及複製／分享提示改為依目前影片位置水平置中。
- 快退／快進提示縮小並增加透明度，減少遮擋影片內容。
- 深色模式下，首頁 Shorts 頻道名稱會使用與觀看次數、發布時間一致的次要文字色。
- Shorts 播放頁的發布時間資訊會依深色／淺色介面調整對比；與影片重疊時固定使用高對比白字。

## 相容性與文件

- 保留舊版 Shorts 畫質欄位的設定格式相容性，匯入舊備份時不會失敗，但不再顯示或套用該欄位。
- 更新繁體中文、English、日本語 README 與 Chrome 商店說明。
- 更新隱私權揭露，明確說明只有一般影片會呼叫 YouTube 畫質介面。
- 使用原本的 YouTube 快速設定工具箱圖示。
