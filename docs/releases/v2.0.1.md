# YouTube 快速設定工具箱 v2.0.1

## 全新工具箱功能

- 新增一鍵影片截圖，可透過面板按鈕或 `Ctrl+S` 擷取不含播放器與網頁 UI 的純影片 PNG。
- 截圖結果可選擇「下載存檔」或「複製到剪貼簿」，並會記住上次選擇。
- 新增首頁與訂閱內容頁的影片排列設定，一般影片與 Shorts 可分別選擇每行 2～6 部，或維持跟隨 YouTube。
- 新增顯示絕對上傳日期，可自訂日期與時間格式；預設關閉。
- 新增隱藏片尾推薦卡，滑鼠移入播放器時可暫時恢復顯示；預設關閉。
- 新增取消自動播放下一部影片；預設關閉並保存設定。

## 複製、分享與快捷鍵

- `S` 與面板主按鈕固定複製「標題＋網址」，`Shift+S` 複製「標題＋目前時間點網址」。
- 複製成功提示期間可按 `F`、`X`、`T`，開啟 Facebook、X、Threads 分享頁。
- 複製格式下拉選單同步提供 Facebook、X、Threads 分享項目。
- 播放速度快捷鍵調整為 `PgUp` 減速、`PgDn` 加速、`Home` 恢復 1×。
- 360° 全景影片不攔截 `S`／`Shift+S`，保留 YouTube 原生全景操作。
- 快捷鍵說明改為獨立彈出視窗，提供更完整且不遮擋的操作說明。

## Shorts 顯示與面板整理

- Shorts 首頁卡片可補上可點擊的頻道名稱及發布時間，播放頁也可顯示發布時間。
- 發布時間會依深色／淺色模式調整對比，與影片重疊時維持高對比白字。
- Shorts 快退、快進、速度與分享提示會依目前影片範圍水平置中。
- Shorts 面板重新整理：主卡保留播放設定，首頁排列、頻道名稱與發布時間整合至「Shorts 顯示設定」。
- 「顯示絕對上傳日期」、「隱藏片尾推薦卡」、「取消自動播放下一部影片」整合至「更多影片設定」。

## 設定備份、相容性與隱私

- 設定備份格式升級至 v4，支援新增設定欄位、匯入預覽、合併或完全取代及匯入前還原點。
- 保留舊版設定遷移與備份相容性。
- 更新繁體中文、English、日本語 README、Chrome 商店文案與隱私權揭露。
- 所有截圖、設定匯入匯出與影片資訊處理都在使用者裝置上完成；不含廣告、追蹤、分析或遠端程式碼。
