# YouTube 快速設定速度 / 畫質 v1.4.0

## 新功能

- 一般影片新增「自動開啟劇院模式」。
- 頻道專屬設定可選擇「跟隨全局」、「強制開啟」或「強制關閉」劇院模式。
- 劇院模式只在每支影片載入時套用一次；使用者後續手動取消時不會再次強制開啟。

## 相容性

- 修正部分影片開頭因相同畫質設定反覆套用，造成媒體來源重建與播放時間不斷回到片頭的問題。
- 相同影片與設定只排程一次，且不會再次點擊已選取的畫質。
- 首次畫質切換若令 YouTube 重建媒體來源並將時間歸零，會恢復切換前的播放位置與播放狀態。
- 修正未訂閱 Premium 時，畫質自動設定可能誤點強化位元率並反覆顯示試用視窗的問題。
- 新增獨立的「使用 Premium 強化畫質」開關，預設關閉；自動最高、4K、1080p 三檔預設皆排除 Premium 畫質。
- 使用者主動開啟後，才會將 `1080p Premium` 納入畫質選擇；頻道專屬設定可獨立保存此開關。
- Shorts 不顯示不適用的劇院模式選項。
- 舊版設定會自動補上預設值，不影響既有速度、畫質與頻道設定。
- Chrome 權限維持不變。
