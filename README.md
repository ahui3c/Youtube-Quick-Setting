# YouTube 快速設定工具箱

[繁體中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

![YouTube 快速設定速度與畫質 4K 宣傳圖](docs/images/promo-zh-4k.png)

自動為 YouTube 一般影片套用播放速度、畫質與頻道專屬設定，並為 Shorts 提供獨立速度與快速操作的 Chrome 擴充功能。

## 主要功能

- 播放速度：`0.7×`、`1×`、`1.25×`、`2×`、`3×`
- 畫質偏好：自動最高、4K、1080p
- 指定畫質不存在時，選擇不超過目標的最高可用畫質
- 「使用 Premium 強化畫質」為獨立開關，預設關閉；開啟後才允許選擇 `1080p Premium`
- 一般影片與 Shorts 使用獨立設定
- 可分別指定首頁與訂閱內容頁的一般影片／Shorts 每行數量（2～6 部），預設跟隨 YouTube 響應式排列
- 可在 YouTube 首頁的 Shorts 卡片補上可點擊的頻道名稱與發布時間，並在 Shorts 播放頁顯示發布時間
- 可將 YouTube 的「2 週前」等相對時間改為絕對上傳日期；預設關閉，支援自訂日期與時間格式
- 可為個別頻道建立專屬設定，優先於同類型的全域設定
- 一般影片可自動開啟劇院模式，並能針對指定頻道跟隨全局、強制開啟或強制關閉
- 可自動關閉一般影片的「自動播放下一部影片」開關；預設關閉並保存使用狀態
- 可隱藏一般影片結尾的推薦卡；預設關閉，滑鼠移入播放器時暫時恢復顯示
- 頻道設定生效時，在播放器右下角顯示兩秒提示
- `PgUp` 降低播放速度、`PgDn` 提高播放速度，`Home` 立即恢復 `1×`
- 按 `S` 或面板主按鈕，固定複製「標題＋網址」；複製提示顯示期間按 `F`／`X`／`T`，開啟對應的 Facebook／X／Threads 分享頁
- 一鍵影片截圖：按面板按鈕或 `Ctrl+S`，將不含播放器與網頁 UI 的純影片 PNG 畫面下載存檔或複製到剪貼簿
- 支援標題＋時間點網址、Markdown、HTML 及頻道＋標題＋網址；`Shift+S` 直接複製標題＋目前時間點網址
- 設定可匯出／匯入 JSON，匯入前提供合併或完全取代預覽，並自動建立還原點
- 播放速度與畫質會盡可能同步至 YouTube 原生設定面板
- 相同影片與畫質設定只排程一次，避免畫質切換造成開頭重複載入
- 支援繁體中文、英文、日文，可跟隨系統或手動選擇
- 設定透過 `chrome.storage.sync` 在 Chrome 中同步保存

## 安裝

1. 下載此專案，或執行：

   ```bash
   git clone https://github.com/ahui3c/Youtube-Quick-Setting.git
   ```

2. 在 Chrome 開啟 `chrome://extensions/`。
3. 開啟右上角「開發人員模式」。
4. 選擇「載入未封裝項目」。
5. 選取本專案資料夾。
6. 開啟 YouTube 影片或 Shorts，點擊工具列上的擴充功能圖示完成設定。

更新程式後，請在 `chrome://extensions/` 對擴充功能按一次「重新載入」，並重新整理 YouTube 分頁。

## 使用方式

### 一般影片與 Shorts

在面板上切換「一般影片」或「Shorts」。一般影片可設定播放速度與畫質；Shorts 可設定播放速度及方向鍵快退／快進。從 Shorts 頁面開啟面板時會自動選取 Shorts。

「首頁每行影片數量」可為一般影片與 Shorts 分別選擇跟隨 YouTube 或固定為 2～6 部。此設定只套用 YouTube 首頁與訂閱內容頁；搜尋、頻道、播放及其他頁面維持 YouTube 原始排列。第一次安裝與舊版升級後均預設跟隨 YouTube。

Shorts 設定中的「首頁 Shorts 顯示頻道名稱」預設開啟，「Shorts 顯示發布時間資訊」第一次安裝時預設關閉。開啟發布時間後，擴充功能會在首頁卡片觀看次數後顯示「2 天前」等相對時間，並在 Shorts 播放頁的頻道與標題之間顯示發布時間；頻道名稱功能則會在首頁卡片標題下方補上可點擊的頻道名稱。播放頁優先讀取 YouTube 當頁已載入的公開發布日期；首頁只為目前顯示的卡片向 YouTube 取得公開資料。查詢結果只在目前頁面快取，不會傳送到第三方伺服器，兩項功能可分別控制。

「顯示絕對上傳日期」第一次安裝時預設關閉。開啟後會將一般影片播放頁與影片清單中的相對時間改為完整日期，並讓已啟用的 Shorts 發布時間使用同一格式。可使用 `yyyy`、`yy`、`MMM`、`MM`、`dd`、`ww`、`HH`、`hh`、`ap`、`mm`、`ss` 自訂顯示；開關與格式會隨其他設定一併保存。

### 頻道專屬設定

在該頻道的影片或 Shorts 頁面開啟面板，啟用「目前頻道優先」。每個頻道都會分別保存一般影片與 Shorts 設定。

### 劇院模式

在「一般影片」頁籤開啟「自動開啟劇院模式」後，進入影片播放頁會透過 YouTube 原生劇院模式按鈕自動切換。每支影片載入時只套用一次；如果之後手動離開劇院模式，擴充功能不會再次強制開啟。頻道專屬設定提供「跟隨全局」、「強制開啟」與「強制關閉」；Shorts 不顯示此項設定。

### 取消自動播放下一部影片

此選項第一次安裝時預設關閉。啟用後，擴充功能會在一般影片載入時關閉 YouTube 播放器的原生自動播放開關，並在 YouTube 嘗試重新開啟時再次關閉；停用選項後不會強制開啟自動播放。設定會透過 Chrome 同步儲存。

### 隱藏片尾推薦卡

此選項第一次安裝時預設關閉。啟用後，一般影片結束時會隱藏 YouTube 的片尾推薦卡與下一部影片推薦區域；將滑鼠移入播放器範圍即可暫時恢復顯示，移出後再次隱藏。此功能不會移除播放途中出現的資訊卡，設定會透過 Chrome 同步儲存。

套用優先順序：

1. 目前頻道＋目前影片類型
2. 目前影片類型的全域設定

### 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| `PgUp` | 切換到下一個較慢速度 |
| `PgDn` | 切換到下一個較快速度 |
| `Home` | 將本次播放恢復為 `1×` |
| `S` | 複製標題＋網址，並短暫啟用社群分享選擇 |
| `F`／`X`／`T` | 在複製提示期間開啟 Facebook／X／Threads |
| `Shift`＋`S` | 複製標題＋目前播放時間點網址 |
| `Ctrl`＋`S` | 依截圖結果設定，下載或複製不含 UI 的純影片 PNG 畫面 |
| `←`／`→` | Shorts 倒退／快進 5 秒 |
| `0` | Shorts 回到片頭 |

在搜尋框、留言框或其他文字輸入區域輸入時，不會攔截這些按鍵。
Shorts 設定頁可將左右方向鍵設為開啟或關閉，並選擇每次跳轉 `3`、`5`（預設）或 `10` 秒；`0` 回片頭不受此開關影響。
`S` 不在目前 YouTube 官方快捷鍵清單中，因此不會占用原生的 `C` 字幕切換功能。
播放 360° 全景影片時，插件不會攔截 `S` 或 `Shift+S`，讓按鍵保留給 YouTube 原生全景視角操作。
截圖直接從影片影格產生，因此不包含 YouTube 控制列、網頁按鈕、插件提示或網頁字幕層；影片本身已燒錄的字幕與圖像仍會保留。面板可選擇「下載存檔」或「複製到剪貼簿」，選擇會被保存，面板按鈕與 `Ctrl+S` 使用相同結果。

### 複製格式與設定備份

複製區的主按鈕與 `S` 快速鍵固定複製「標題＋網址」；複製成功提示顯示期間，可按 `F`、`X`、`T` 開啟 Facebook、X、Threads。這些平台會透過分享網址預填公開影片資訊；右側箭頭選單也提供相同的分享項目。其他格式只會單次複製，不會改變主按鈕與快速鍵的預設。

各平台最終顯示的標題、縮圖與文字排列由平台依 YouTube 公開連結資料決定。若瀏覽器阻擋彈出視窗，插件會顯示失敗提示，不會持續重試。

「設定備份與還原」可匯出格式版本 `v4` 的 JSON 檔。匯入時會先顯示一般設定變更與頻道新增、更新、移除數量，並可選擇「合併設定」或「完全取代」。套用前會在 `storage.local` 自動建立一個匯入前還原點；設定檔及還原點不會傳送給開發者。

## 畫質行為

如果影片沒有指定解析度，擴充功能會選擇不超過目標的最高畫質。例如設定 4K、影片最高只有 1440p 時，會選擇 1440p。如果所有可用畫質都高於目標，則選擇最接近的較高畫質。

自動最高、4K、1080p 三個解析度選項預設都會排除 Premium 畫質。只有使用者主動開啟「使用 Premium 強化畫質」後，`1080p Premium` 才會加入可選範圍；未訂閱 Premium 的使用者應維持關閉，避免觸發試用視窗。頻道專屬設定可獨立保存此開關。

目前桌面版 YouTube Shorts 沒有穩定可用的原生畫質控制，因此 Shorts 設定頁不提供畫質選項，也不會在背景強制套用畫質；Shorts 播放速度與快速操作不受此限制。

## 開發與測試

此專案使用 Chrome Manifest V3，主要檔案如下：

- `popup.html`／`popup.js`／`popup.css`：設定介面與多語系
- `content.js`：YouTube 導航、頻道偵測、快捷鍵與提示
- `copy-utils.js`：五種影片資訊複製格式、時間點網址與社群分享網址
- `settings-transfer.js`：設定檔版本、匯入合併與差異預覽
- `page-bridge.js`：同步 YouTube 播放器狀態與原生設定面板
- `_locales/`：Chrome 擴充功能名稱與說明的系統語言版本
- `tests/`：畫質選擇、設定遷移、快捷鍵與介面渲染測試

安裝開發相依套件並執行全部測試：

```powershell
npm install
npx playwright install chromium
npm test
```
