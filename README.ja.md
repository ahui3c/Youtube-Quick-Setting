# YouTube クイック設定ツールボックス

[繁體中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

![YouTube 速度・画質クイック設定 4K プロモーション画像](docs/images/promo-ja-4k.png)

YouTube の通常動画に再生速度・画質・チャンネル別設定を適用し、ショートには個別の速度設定とクイック操作を提供します。Chrome を安定版の基準とし、Firefox は分離ビルド、Safari は変換準備用出力を提供します。

## 主な機能

- 再生速度：`0.7×`、`1×`、`1.25×`、`2×`、`3×`
- 画質設定：最高画質、4K、1080p
- 指定画質がない場合、目標以下で利用できる最高画質を選択
- 「Premium 高画質を使用」は既定でオフの独立した設定で、オンの場合のみ `1080p Premium` を許可
- 通常動画とショートを個別に設定
- ホームと登録チャンネルで、通常動画／ショートの1行あたりの数を2～6本に個別設定可能。既定では YouTube のレスポンシブ配置に従う
- YouTube ホームのショートカードにクリック可能なチャンネル名と公開時刻を追加し、ショート再生ページにも公開時刻を表示
- 「2 週間前」などの相対時刻を、書式を指定できる絶対アップロード日時へ任意で置換
- チャンネル専用設定は同じ動画タイプの全体設定より優先
- 通常動画ではシアターモードを自動的に有効化でき、チャンネルごとに全体設定に従う／常にオン／常にオフを選択可能
- 通常動画の「次の動画を自動再生」を自動的にオフにでき、既定はオフで前回の状態を保存
- 通常動画の終了画面のおすすめを非表示にし、プレーヤーにポインターを重ねた時だけ一時表示可能。既定はオフで状態を保存
- チャンネル設定の適用時、プレーヤー右下に速度と画質を2秒間表示
- `PgUp` で減速、`PgDn` で加速、`Home` で即座に `1×` へ戻す
- `S` キーまたはメインボタンで「タイトル＋URL」をコピーし、確認表示中に `F`／`X`／`T` で Facebook／X／Threads を開く
- ポップアップのボタンまたは `Ctrl+S` で、プレーヤーやページ UI を含まない現在の動画フレームを PNG 保存またはクリップボードへコピー
- タイトル＋現在位置 URL、Markdown、HTML、チャンネル＋タイトル＋URL に対応し、`Shift+S` でタイトル＋現在位置 URL を直接コピー
- JSON 設定の書き出し／読み込み、結合／置換プレビュー、読み込み前の自動復元ポイントに対応
- プレーヤーが許可する場合、YouTube 標準の速度・画質メニューにも同期
- 同じ動画・画質設定の適用を1回にまとめ、冒頭の繰り返し読み込みを防止
- 繁体字中国語、英語、日本語に対応し、システム連動または手動選択が可能
- 設定は `chrome.storage.sync` に保存

## インストール

1. このリポジトリをダウンロードするか、次を実行します。

   ```bash
   git clone https://github.com/ahui3c/Youtube-Quick-Setting.git
   ```

2. Chrome で `chrome://extensions/` を開きます。
3. **デベロッパーモード**を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**を選択します。
5. このプロジェクトフォルダーを指定します。
6. YouTube 動画またはショートを開き、拡張機能アイコンから設定します。

ファイルを更新した後は、`chrome://extensions/` で拡張機能を再読み込みし、YouTube のタブも更新してください。

### ウェブストア版と未パッケージ版を同時に使用する場合

この調整機能に対応した Chrome ウェブストア版と未パッケージ版が同時にインストールされている場合、YouTube 上で互いを認証してバージョンを比較します。新しいバージョンだけが動作し、古いバージョンは YouTube の全機能を停止してツールバーに `OLD` を表示します。同じバージョンでは未パッケージ版が優先され、Chrome ウェブストア版が停止します。停止中のパネルには優先バージョンが表示され、設定の適用や書き込みは行いません。

完全に動作させるには、両方のバージョンがこの調整機能を搭載している必要があります。対応前の旧バージョンを新しい版から遠隔停止することはできません。優先版を削除または無効にすると、停止中だった版は自動的に再開します。

## 使い方

**通常動画／ショート**の切り替えで、それぞれの設定を編集できます。ショートのページからパネルを開くと、自動的にショート設定が選択されます。

「ホームの1行あたりの動画数」では、通常動画とショートを個別に YouTube に従う、または2～6本へ固定できます。ホームと登録チャンネルだけに適用され、検索、チャンネル、再生などのページは YouTube の元の配置を維持します。新規インストールと旧版からの更新時はいずれも YouTube に従う設定です。

「ホームのショートにチャンネル名を表示」は既定でオン、「ショートの公開時刻情報を表示」は初回インストール時に既定でオフです。公開時刻を有効にすると、ホームのカードでは視聴回数の後に「2日前」などの相対時刻、ショート再生ページではチャンネル情報とタイトルの間に公開時刻を表示します。チャンネル名の設定は、ホームのカードタイトル下にクリック可能な名前を個別に追加します。再生ページは YouTube がすでに読み込んだ公開日を優先して利用し、ホームでは現在表示されているカードだけ公開情報を YouTube から取得します。結果は現在のページ内だけでキャッシュされ、第三者サーバーには送信されません。

「アップロード日を絶対日付で表示」は初回インストール時にオフです。有効にすると、通常動画の再生ページと動画一覧の相対時刻を完全な日付へ置き換え、有効なショート公開時刻にも同じ形式を適用します。`yyyy`、`yy`、`MMM`、`MM`、`dd`、`ww`、`HH`、`hh`、`ap`、`mm`、`ss` を使用でき、スイッチと形式は他の設定とともに保存されます。

チャンネル別に設定する場合は、そのチャンネルの動画またはショートでパネルを開き、**現在のチャンネルを優先**を有効にします。通常動画とショートの設定は別々に保存されます。

### シアターモード

「通常動画」で「シアターモードを自動的に有効化」をオンにすると、動画を開いたときに YouTube 標準のシアターモード操作で自動切り替えします。適用は動画の読み込みごとに1回だけで、その後に手動でシアターモードを解除しても再度強制しません。チャンネル設定では「全体設定に従う」「常にオン」「常にオフ」を選択できます。ショートでは表示されません。

### 次の動画の自動再生を無効化

初回インストール時はオフです。有効にすると、通常動画の読み込み時に YouTube 標準の自動再生スイッチをオフにし、YouTube が再度オンにした場合もオフへ戻します。この設定を無効にしても自動再生を強制的にオンにはしません。設定はブラウザーの同期ストレージへ保存されます。

### 終了画面のおすすめを非表示

初回インストール時はオフです。有効にすると、通常動画の終了時におすすめカードと次の動画エリアを非表示にします。プレーヤーへポインターを重ねると一時的に表示し、外すと再び非表示になります。動画途中の情報カードには影響せず、設定はブラウザーの同期ストレージへ保存されます。

適用優先順位：

1. 現在のチャンネル＋現在の動画タイプ
2. 現在の動画タイプの全体設定

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `PgUp` | 次の遅い再生速度を選択 |
| `PgDn` | 次の速い再生速度を選択 |
| `Home` | 現在の再生を `1×` に戻す |
| `S` | タイトル＋URL をコピーし、短時間だけ共有キーを有効化 |
| `F`／`X`／`T` | コピー確認中に Facebook／X／Threads を開く |
| `Shift`＋`S` | タイトル＋現在の再生位置を含む URL をコピー |
| `Ctrl`＋`S` | 設定に従い、UI を含まない PNG フレームを保存またはコピー |
| `←`／`→` | ショートを 5 秒戻す／進める |
| `0` | ショートの先頭に戻る |

検索欄、コメント欄などへの文字入力中はショートカットを使用しません。
ショート設定では左右キーを無効にしたり、移動秒数を `3`、`5`（既定）、`10` 秒から選択できます。左右キーを無効にしても `0` の先頭移動は使用できます。
`S` キーは現在の YouTube 公式ショートカット一覧に含まれていないため、標準の `C` 字幕切り替えはそのまま利用できます。
360° 動画では `S` と `Shift+S` を拡張機能が取得せず、YouTube 標準の全景視点操作にそのまま使用できます。
スクリーンショットは動画フレームから直接生成されるため、YouTube の操作バー、ページボタン、拡張機能の通知、Web 字幕レイヤーは含まれません。動画自体に焼き込まれた字幕や画像は残ります。ポップアップで「ファイルに保存」または「クリップボードにコピー」を選択でき、その選択は保存され、ボタンと `Ctrl+S` の両方に適用されます。

### コピー形式と設定バックアップ

メインのコピーボタンと `S` キーは常に「タイトル＋URL」をコピーします。確認表示中に `F`、`X`、`T` を押すと Facebook、X、Threads を開きます。各プラットフォームは共有 URL で公開動画情報を事前入力します。矢印メニューにも同じ共有項目があります。

最終的なタイトル、サムネイル、文字の配置は各プラットフォームが決定します。ポップアップがブロックされた場合はエラーを表示し、自動再試行しません。

「設定のバックアップと復元」は形式バージョン `v4` の JSON を書き出します。読み込み前に一般設定の変更数とチャンネルの追加・更新・削除数を表示し、「設定を結合」または「すべて置換」を選択できます。適用前には端末内に復元ポイントを自動作成し、設定ファイルや復元ポイントを開発者へ送信しません。

## 画質の動作

指定した解像度がない場合、目標以下で利用可能な最高画質を選択します。すべての画質が目標より高い場合は、最も近い高画質を選択します。

最高画質、4K、1080p の3項目は、既定では Premium 画質を除外します。ユーザーが「Premium 高画質を使用」を明示的にオンにした場合のみ `1080p Premium` が候補になります。未登録の場合は、体験案内を避けるためオフのまま使用してください。チャンネル設定ではこのスイッチも個別に保存します。

現在のデスクトップ版ショートには安定して利用できる標準画質コントロールがないため、ショート設定では画質項目を表示せず、バックグラウンドでも画質を強制しません。ショートの再生速度とクイック操作には影響しません。

ブラウザー標準の PiP または Document Picture-in-Picture のフローティングプレーヤーが動作中は、未完了の画質、プレーヤー UI、再生位置の再試行を一時停止します。別の PiP ツールが実際の動画要素をフローティングドキュメントへ移動するときの干渉を防ぎ、終了後も事前に適用された速度と画質は維持されます。

## プライバシー

- 個人データを収集、送信、販売しません。
- 外部アクセス解析を使用しません。
- `youtube.com` 上でのみ動作します。
- 設定はブラウザーの同期ストレージだけに保存します。

詳細は [プライバシーポリシー](PRIVACY.md) をご覧ください。

## 開発

Chrome Manifest V3 を使用しています。`tests/` には、画質フォールバック、旧設定の移行、キーボード操作、多言語パネル表示のテストがあります。`npm install`、`npx playwright install chromium`、`npm test` の順に実行すると、すべてのテストを確認できます。

## Firefox / Safari ビルド

`pnpm run build:firefox` を実行し、Firefox の `about:debugging` から `dist-firefox/manifest.json` を一時的に読み込みます。`pnpm run package:firefox` で未署名の AMO アップロード用 ZIP を作成できます。詳細は [Firefox 開発ガイド](docs/FIREFOX.md) を参照してください。

`pnpm run build:safari` は `dist-safari/` を生成します。その後 macOS の Xcode で変換・署名してください。これは Safari 実機検証済みの App Store ビルドではなく、変換準備用出力です。詳細は [Safari 準備ガイド](docs/SAFARI.md) を参照してください。

繁体字中国語、英語、日本語の 4K プロモーション素材は `docs/images/` に収録しています。
